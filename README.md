# Амфодент — варианты лендинга

Два исходных макета первого экрана лендинга:

- **Эмаль** — `enamel/Main.dc.html`.
- **Стерильный свет** — `sterile-light/Sterile.dc.html`.

Общая страница выбора — `index.html`. Страница `viewer.html` позволяет переключать варианты и масштабирует исходный макет под ширину окна. Оригинальные файлы экспорта сохранены без изменений.

Просмотр: https://evseviaesfi.github.io/amfodent-landing-variants/

Это демонстрационные макеты. Кнопки внутри не подключены к заказам или CRM.
